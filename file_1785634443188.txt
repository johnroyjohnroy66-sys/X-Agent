### 1. **Temperature Converter (Celsius ↔ Fahrenheit)**

```python
# Celsius to Fahrenheit
celsius = float(input("Celsius temperature dijiye: "))
fahrenheit = (celsius * 9/5) + 32
print(f"{celsius}°C = {fahrenheit}°F")

# Fahrenheit to Celsius
f = float(input("Fahrenheit temperature dijiye: "))
c = (f - 32) * 5/9
print(f"{f}°F = {c:.2f}°C")
```

### 2. **Guess the Number Game (Simple)**

```python
import random

secret = random.randint(1, 10)
guess = int(input("1 se 10 ke beech ek number guess karo: "))

if guess == secret:
    print("🎉 Wah! Sahi jawab!")
else:
    print(f"❌ Galat! Secret number tha {secret}")
```

### 3. **List Sum & Average**

```python
numbers = [10, 20, 30, 40, 50]
total = sum(numbers)
average = total / len(numbers)
print(f"Numbers: {numbers}")
print(f"Sum: {total}")
print(f"Average: {average}")
```
